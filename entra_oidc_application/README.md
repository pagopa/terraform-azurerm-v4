# entra_oidc_application

Creates a generic Entra ID App Registration + Enterprise Application for an OIDC confidential client (groups claim, User.Read with admin consent, group assignments, client secret). Unlike `keycloak_entra`, the display name is fully provided by the caller.

## Example

```hcl
module "argocd_entra" {
  source = "./.terraform/modules/__v4__/entra_oidc_application"

  display_name           = "${local.project}-argocd"
  redirect_uris          = ["https://argocd.example.com/auth/callback"]
  authorized_group_names = ["my-admins"]
  ad_user_owners         = ["owner@example.com"]
}
```
